## tablX — консольная утилита для красивого отображения csv-таблиц.

программа написана на **go** и предоставляет следующие возможности:

  \> **поддержка формата .csv**, использующего разделитель ';'.
  
  \> **автоматическое выравнивание столбцов** с учетом длины содержимого.
  
  \> **динамическое формирование заголовков** буквенными обозначениями ('A', 'B', 'C', ...) в зависимости от кол-ва столбцов.
  
  \> **автоматическая нумерация строк** с динамическим расчетом отступов под размерность индексов.
  
  \> **выравнивание по центру** внутри ячеек с аккуратной разделительной сеткой ('|').
